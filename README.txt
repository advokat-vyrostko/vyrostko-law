САЙТ-ПОРТФОЛІО АДВОКАТА ВИРОСТКА АЛЬБІНА ВІКТОРОВИЧА

Файли:
- index.html — головна сторінка
- about.html — про адвоката
- practice.html — напрями практики
- cases.html — судова практика
- publications.html — публікації
- contacts.html — контакти
- styles.css — дизайн та адаптивність
- script.js — мобільне меню
- assets/hero-office.jpg — тематичне зображення першого екрана

Перегляд:
1. Розпакуйте архів.
2. Відкрийте index.html у браузері.

Публікація:
Сайт можна розмістити безкоштовно через GitHub Pages. Для цього створіть репозиторій GitHub,
завантажте всі файли зі збереженням структури папок і ввімкніть Pages у Settings -> Pages.

Перед публікацією перевірте контактні дані, адресу та тексти. Форма звернення наразі відкриває поштовий клієнт через mailto;
вона не зберігає повідомлення на сервері. Судова практика та публікації залишені без вигаданих кейсів і статей.
